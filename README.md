## 👋 E aí, tudo certo?

Sou o **Artur**, desenvolvedor Full Stack direto do Brasil 🇧🇷. Gosto de construir aplicações rápidas, escaláveis e bem organizadas — do front-end bonito até o back-end que aguenta o tranco na sexta-feira às 18h.

Curto resolver problema chato com código, automatizar tudo que dá preguiça e aprender alguma coisa nova no meio do caminho. Sem fórmula mágica: café, documentação e `console.log` até dar certo.

> 💭 *"Se funciona, não mexe. Se não funciona... aí sim, bora entender o porquê."*

## 🎯 No que eu boto energia

- 🧩 **Full Stack de verdade** — interface, API e banco conversando direitinho
- ⚡ **Performance** — menos espera, mais resposta
- 🏗️ **Arquitetura limpa** — código que a próxima pessoa (ou eu em 3 meses) entende
- 🎨 **UX/UI** — software feio pode até funcionar, mas ninguém merece
- 🤖 **Automação** — se dá pra scriptar, não faço na mão duas vezes
